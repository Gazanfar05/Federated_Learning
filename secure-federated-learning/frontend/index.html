Academic Security & Cryptographic Architecture:

This module illustrates the twin pillars of privacy in our architecture: 1) Secure Aggregation via Pairwise Additive Masking (preventing the central server from inspecting raw hospital model updates) and 2) Differential Privacy via DP-SGD (preventing model inversion and membership inference attacks on the final global model).
